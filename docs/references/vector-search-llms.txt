# Vector Search Reference Summary For LLMs And Engineers

Purpose: 给 AI 和工程人员消费的向量检索摘要，不是官方文档原文复制。

Sources:
- https://lancedb.github.io/lancedb/
- https://platform.openai.com/docs

Project mapping:
- 语义检索和向量库属于首期架构主线。
- 向量检索用于召回相关章节、设定、事件和角色资料。
- 向量结果不是正式事实源。

Candidate directions:
- OpenAI embedding API + 本地向量索引。
- 嵌入式向量库。
- 轻量向量索引作为首期回退。

Key constraints:
- 索引必须可重建。
- 正式事实仍来自用户确认。
- embedding 更新应与章节、设定、事件变更关联。

Risks:
- 本地索引体积增长。
- embedding 成本。
- 语义召回误命中导致 AI 上下文污染。
