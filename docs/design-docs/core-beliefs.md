# Core Beliefs

## 目的

记录项目长期不轻易变化的稳定设计信念。

## 稳定原则

### 人工确认高于 AI 自动写入

AI 可以生成、抽取、解释和建议，但不能绕过用户确认写入正式设定、事件、关系或状态。

### 正文不是唯一事实源

正文是叙事表达，正式事实来自已确认设定和事件。正文可以作为候选事实来源，但不能自动成为事实源。

### 事件驱动状态

角色位置、道具持有、关系变化、技能状态和人物状态必须能追溯到事件。

### 世界内时间与叙事顺序分离

倒叙、插叙、回忆和梦境不改变事件在故事世界中的真实发生顺序。

### 本地优先

作品数据默认保存在本地。外部 AI API 只是可选计算能力，不是数据事实源。

### 检查不阻断创作

强约束问题必须标红并说明，但不强制禁止用户继续写作。

### 修复必须可预览和可回滚

任何一键修复都必须生成补丁预览，并在应用后可通过版本机制恢复。

### 索引不是事实源

图索引、向量索引、全文索引、检查结果索引都必须可重建。
