# Time State Graph Spec

## 目的

定义时空状态机和知识图谱的用户可见能力。

## 用户目标

用户需要精确判断某时间、某地点、某角色的关系、道具持有、人物状态和能力可用性。

## 核心查询场景

- 某角色在某时间点在哪里。
- 某道具在某时间点由谁持有。
- 某两个角色在某章节前是什么关系。
- 某角色在某事件后是否受伤。
- 某技能在某章节是否可用。
- 某事件是否违反时间域或历法规则。

## 时间配置

用户应能配置：

- 架空历法名称。
- 时间单位。
- 时间显示格式。
- 时间域。
- 时间流速映射。

## 事件绑定

支持两种方式：

- 用户手动创建事件并绑定章节或正文片段。
- AI 从正文中抽取候选事件，用户确认后入库。

## 状态显示

状态视图应展示：

- 实体。
- 时间点或时间区间。
- 当前状态。
- 来源事件。
- 影响章节。
- 是否存在冲突。

## 冲突显示

- `error`：强约束冲突。
- `warning`：因果链或设定不完整。
- `notice`：可补充信息。

## 验收标准

- 可以查询角色位置链。
- 可以查询道具持有链。
- 可以查询关系变化路径。
- 可以区分世界内时间和叙事顺序。
- 可以配置至少一个非主时间域和时间流速规则。

## 当前 Spike 记录

- `spikes/tauri-minimal` 已验证一个非主时间域 `Mirror Realm` 和主时间域 `Prime World` 的流速映射样例。
- 已验证 `mirror-realm:45` 可映射为 canonical `world_tick=1025`。
- 已验证倒叙事件可保持叙事顺序靠后但世界内时间更早。
