记录项目中的结构性技术债、延迟决策和已知折中。


### TD-DEBT-002 多数据库快照一致性和正式快照元数据策略未验证

状态：open

来源：`spikes/tauri-minimal` 已验证单 SQLite 项目数据库文件可通过文件复制恢复；多数据库组合下的快照一致性、正式快照元数据策略和热备份边界尚未验证。

影响范围：版本回滚、崩溃恢复、迁移策略。

当前缓解措施：首期优先把事实源收敛到单 SQLite 文件，并将全文索引、向量索引和图缓存视为可重建派生数据；恢复前释放数据库连接或使用 SQLite backup API。

偿还触发条件：引入专用图数据库、独立向量库或任何第二个事实源数据库前，完成多数据库一致性快照 spike。

优先级：P0

关闭标准：`RELIABILITY.md` 中明确单 SQLite 与多数据库快照实现策略、快照元数据字段、恢复流程和索引重建策略。
