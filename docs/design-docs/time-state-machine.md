# Time State Machine

## 目的

定义强约束时空状态机，包括架空历法、多时间域、不同时间流速、倒叙和事件级状态推导。

## 基本概念

### World Time

事件在故事世界中真实发生的时间。

### Narrative Order

事件在正文中被叙述的顺序。

### Calendar

用户可配置的架空历法。

### Time Domain

具有独立时间流速或时间规则的域，例如现实世界、秘境、梦境、回忆、幻境。

### Time Scale Rule

时间域之间的流速映射规则。

## 必须支持的场景

- 架空历法。
- 倒叙。
- 回忆。
- 不同时间流速。
- 事件级追踪。
- 时间戳级查询。

## 状态机输入

- 已确认事件。
- 已确认设定。
- 用户配置的历法。
- 用户配置的时间域。
- 用户确认的关系变化。
- 用户确认的状态变化。

## 状态机输出

- 某时间点角色位置。
- 某时间点道具持有者。
- 某时间点人物关系。
- 某时间点角色状态。
- 某时间点技能或能力可用性。
- 冲突检查结果。

## 约束规则示例

- 同一角色不能在同一时间出现在两个互斥地点。
- 同一道具不能在同一时间被两个实体持有，除非设定允许复制体。
- 已死亡角色不能参与死亡后的非回忆事件。
- 角色不能使用尚未获得或已被封印的能力。
- 关系变化应由事件解释。

## 时间域映射

时间域配置必须表达：

- 时间域名称。
- 起始锚点。
- 结束锚点。
- 与主时间域的换算规则。
- 是否允许嵌套时间域。
- 是否允许不可逆时间跳转。

## 倒叙处理

倒叙事件必须同时记录：

- 真实发生时间。
- 当前叙述章节。
- 叙述顺序。
- 是否影响当前时间线状态。

## 增量推导

当事件、状态、关系或时间配置变化时，系统应计算影响范围：

- 受影响实体。
- 受影响时间区间。
- 受影响章节。
- 受影响检查结果。

## Open Questions

- 时间域配置 UI 的具体表达方式待设计。
- 多时间域嵌套的最大复杂度需要限制。
