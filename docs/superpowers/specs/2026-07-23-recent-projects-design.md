# 最近项目启动列表设计

## 目标

启动页显示最多 8 个最近成功创建或打开的本地项目。用户可直接重新打开、显式移除失效记录，且存储损坏或浏览器拒绝存储时不影响创建/打开主流程。

## 数据与持久化

使用版本化 localStorage 键 `super-novel.recent-projects.v1`，每项包含 `name`、`directory` 和 `lastOpenedAtMs`。Windows 路径以小写形式比较去重，但保留原始路径显示。每次成功 create/open/recent-open 后将项目置顶；列表按最近时间降序并截断为 8 项。

读取时仅接受字段类型完整的数组项。JSON 损坏、SecurityError、QuotaExceededError 或其他存储异常均安全降级：读取返回空列表，写入失败仍保留当前会话内的 React 状态，不泄露异常。

## 交互

最近项目位于现有“打开已有项目”操作下方，沿用扁平分隔线而非新增卡片。每项展示名称和路径，并提供“打开”和“移除”两个明确操作。

点击最近项目直接调用现有 `api.openProject(directory)`。失败时不自动删除，保留安全错误消息并让用户显式移除；成功时刷新名称和时间、置顶后进入工作台。所有最近项目操作服从现有全局 busy 状态。

## 验证

StartScreen 测试覆盖成功记录、去重排序、8 项上限、recent 打开、失败保留和显式移除、坏 JSON 与存储异常。App 测试覆盖无活动项目时最近列表随启动页出现。全量前端测试、类型检查与生产构建必须通过。
