# Project Console And Workbench Spec

## 目的

定义作品控制台和分栏工作台的用户可见行为。

## 用户目标

用户打开一个作品后，应能在同一工作台中管理章节、正文、设定、事件、检查结果和 AI 操作。

## 作品控制台必须展示

- 作品名称。
- 章节列表。
- 最近编辑内容。
- 检查状态摘要。
- 当前快照信息。
- 常用 AI 操作入口。
- Markdown 导出入口。

## 分栏工作台

### 左栏

- 卷、章节、场景树。
- 章节检查状态。
- 快速切换章节。

### 中栏

- 正文编辑。
- 章节大纲。
- 场景内容。
- 冲突标红。

### 右栏

- 当前章节涉及设定。
- 当前章节绑定事件。
- 当前实体状态。
- 检查结果列表。
- AI 操作面板。
- 修复补丁预览。

## 关键用户流

### 编辑章节

1. 用户选择章节。
2. 中栏显示正文。
3. 右栏显示相关设定和事件。
4. 用户编辑正文。
5. 系统保存内容并标记待检查范围。

### 触发检查

1. 用户点击检查当前章节或全作品。
2. 系统显示检查进度。
3. 结果在章节树、中栏正文和右栏检查面板显示。

### 应用修复

1. 用户选择检查结果。
2. 请求生成修复补丁。
3. 系统按类型展示补丁。
4. 用户分别授权。
5. 系统应用补丁并触发增量检查。

## 验收标准

- 用户能在一个界面看到章节、正文、设定、事件和检查结果。
- 用户能手动触发检查。
- `error` 级问题必须醒目标红。
- 用户能只应用部分修复补丁。
