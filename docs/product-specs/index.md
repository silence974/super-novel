# Product Specs Index

## 目的

本目录存放产品规格文档，定义用户可见行为和验收口径。

## 当前核心规格

- `project-console-and-workbench.md`：作品控制台与分栏工作台。
- `time-state-graph.md`：时空状态机与知识图谱。
- `ai-assisted-writing-and-review.md`：AI 辅助写作、抽取、检查和修复。

## 规格状态

| `project-console-and-workbench.md` | draft | P0 |
| `time-state-graph.md` | draft | P0 |

## 更新规则

- 新增用户可见功能时必须新增或更新 spec。
- 修改产品行为时必须同步相关设计文档。
- spec 不应定义底层数据库实现细节。
